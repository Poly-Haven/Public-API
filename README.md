# Poly Haven API

The public API used by polyhaven.com itself, as well as any third party applications.

Provides endpoints for getting lists of assets, categories, and information about individual assets as well.

Currently live at https://api.polyhaven.com

Free to use for any purpose, personal or commercial, forever. The assets themselves are CC0 and never require attribution — but building on the live API specifically requires a small "Powered by Poly Haven" credit. See the Terms of Service below for details.
